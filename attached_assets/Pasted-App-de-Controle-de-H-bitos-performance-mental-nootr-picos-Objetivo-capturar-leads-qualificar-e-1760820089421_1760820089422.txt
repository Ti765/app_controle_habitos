App de Controle de Hábitos (performance mental + nootrópicos)
Objetivo: capturar leads, qualificar e apoiar conversão.
Proposta: elevar potencial humano via hábitos + suplementação.
Público: produtividade, alta performance, biohacking, cognição.
Estilo visual obrigatório: Liquid Glass Design (glassmorphism fluido) — aplicar em navbar, cards e modais: fundo semitransparente, blur sutil, brilho/reflexos leves, borda suave, sombras discretas; manter performance (iOS: expo-blur; Android: fallback com opacidade/overlays).

Stack

React Native (Expo SDK 51+) + TypeScript

UI: NativeWind, Reanimated v3, React Native SVG, Expo Vector Icons/lucide-react-native

Navegação: Expo Router (file-based)

Estado: Zustand

Backend mock: AsyncStorage (pronto para REST/GraphQL)

Forms/validação: React Hook Form + Zod

Estrutura (obrigatória)

app/(tabs)/home.tsx, habits.tsx, insights.tsx, profile.tsx • app/onboarding/{welcome,select-habits,permissions}.tsx • app/modals/{check-in,add-habit,habit-detail}.tsx • app/_layout.tsx

constants/{Colors,Tokens,Config}.ts • utils/{date-helpers,validators,formatters}.ts • assets/{fonts,images}
Naming: screens/utils/lib em kebab-case; componentes em PascalCase.

Design System

DARK (padrão): bg #0e1114, bgElev #1a1d24, text #e7ebf3, textDim #a4adbd, accent #18b7c7 (pressed/subtle/border), ring rgba(24,183,199,0.4).
LIGHT: bg #ffffff, bgElev #f5f5f7, text #1d1d1f, accent #0071e3 (pressed/subtle/border), ring rgba(0,113,227,0.3).
Tokens: spacing 4–48 (4pt), radius md=10 (crítico), shadows sm/md/lg sutis (estilo macOS), tipografia 11–36, pesos 400–700, line-height 1.25/1.5/1.6.
Liquid Glass: usar BlurView nas surfaces elevadas (hero/headers/modals) + borda 1px sutil e highlight/overlay suave; evitar ruído visual.

Componentes

Button: primary/secondary/ghost/danger; sm/md/lg; estados (hover/press/disabled/loading); props (variant,size,onPress,children, ícones, loading); Reanimated spring.
Card: elevation 0/1/2, interactive, padding sm/md/lg; bgElev + radius 10 + borda sutil; press: translateY(-2).
EnergyRing: SVG 160px, stroke 12, traço animado; valor central + label; props value, size?, strokeWidth?.
PillarCard: ícone+título, valor, progress bar, quick action; radius 10; scale(.98) ao press.
HabitItem: checkbox 28×28 (pop), título/meta, streak badge; swipe editar/remover.
ProgressBar: 6px, bg separator, fill accent, animação ao mudar.

Overlay escuro + blur; modal bgElev (radius 16, padding 24); título/subtítulo; escala 1–10 (botões 44px, selecionado = accent + scale); sintomas (pills) multi-select; salvar/cancelar. Animações: slide-up+fade (in 300ms), fade out 200ms, seleção com spring.
